# 关于我

你好，我是 **小小人仁**。

这个博客主要记录我的安全研究、开发实践和学习笔记。我希望这里不只是一份知识清单，也能留下解决问题时的思路、踩过的坑，以及一些尚未完成的探索。

## 我在关注什么

- 网络空间安全、网络攻防与自动化安全研究
- Python、Java 与后端开发
- 数据结构、算法和计算机基础
- Linux、Git 及开发工具的实践
- 技术文章写作与知识整理

我主要使用 **Python** 和 **Java**，接触过 Django、Spring Boot、MySQL、SQLite 等技术，也在持续补充网络安全与工程实践方面的能力。能够阅读英文技术文档、论文和技术手册，是我学习新知识时很重要的一项工具。

## 学习经历

我本科就读于烟台大学计算机科学与技术专业，系统学习了数据结构、计算机组成原理、操作系统、计算机网络、数据库系统、C/C++、Python 和软件工程等课程。

本科毕业后，我进入齐鲁工业大学攻读网络空间安全硕士学位。目前的学习内容包括密码学、计算机网络、网络攻防、数据结构与算法、操作系统和数据库原理。我希望在夯实基础的同时，把安全研究落实到真正可复现、可验证的实践中。

## 做过的一些项目

### 学生信息管理系统

使用 **Python、Django 和 MySQL** 完成后端逻辑、数据库设计与接口实现，支持学生信息管理、成绩统计和权限管理等功能。这段经历让我第一次较完整地理解了一个 Web 系统从数据建模到功能落地的过程。

### 排序算法可视化系统

使用 **C++ 和 Qt** 实现快速排序、归并排序、冒泡排序等八种经典算法的动态演示和效率对比。相比只在纸面上推导复杂度，把算法的执行过程真正“画出来”，让我对数据结构与性能有了更直观的认识。
